# Plantilla: entrevista semiestructurada para investigar una tarea

**Objetivo:** comprender cómo una persona resolvió una tarea real.  
**Sesión:** [ID], [fecha], [contexto]  
**Consentimiento:** verificar y documentar por proceso separado y seguro.

## Apertura (lectura adaptada)
«Queremos comprender cómo realizas [tarea]. Estamos evaluando el sistema y el proceso, no tus habilidades. Puedes dejar de participar o evitar cualquier pregunta. [Explicar responsables, recogida, grabación voluntaria, uso, conservación y contacto según el consentimiento entregado]. ¿Tienes preguntas antes de comenzar?»

## Preguntas principales
1. «¿Cuándo fue la última vez que necesitaste [resultado]?». 
2. «¿Qué estaba ocurriendo ese día y por qué lo necesitabas?». 
3. «¿Qué hiciste primero?». 
4. «¿Qué opciones consideraste?». 
5. «¿Qué sucedió después?». 
6. «¿Cómo supiste que habías terminado correctamente?». 
7. «¿Recuerdas alguna vez en que no pudiste completar la tarea?». 
8. «¿Hay algo importante que no te pregunté?». 

## Repreguntas neutrales
- «¿Me das un ejemplo concreto?». 
- «¿Qué esperabas que sucediera?». 
- «¿Qué hiciste cuando apareció ese mensaje?». 
- «¿Cómo comprobaste el resultado?». 

## Registro (distinguir)
| Momento | Cita o acción literal | Interpretación / pregunta pendiente |
|---|---|---|
| | | |

## Cierre
Agradecer; preguntar por aclaraciones; recordar el uso de los datos, la confidencialidad limitada y las opciones acordadas para detener o retirar la participación.

**No preguntar** «¿Te gustaría que agregáramos el botón X?» antes de comprender el problema. Si se evalúa un prototipo, documentarlo como una actividad distinta de observación de tareas.
